# Session 01 — What is geopolitical risk?

### Concepts, indicators, and the syllabus

> **Before we can manage geopolitical risk, what exactly are we counting?**

| | |
|---|---|
| **Big work** | Caldara, D., & Iacoviello, M. (2022). Measuring geopolitical risk. *American Economic Review*, 112(4), 1194–1225. [doi:10.1257/aer.20191823](https://doi.org/10.1257/aer.20191823) |
| **Target figure** | The monthly GPR index since 1985, with its spikes labelled — and its historical counterpart since 1900 |
| **Data you collect** | The GPR index, from the authors' page: [matteoiacoviello.com/gpr.htm](https://www.matteoiacoviello.com/gpr.htm) |
| **Tableau skill** | Connect to an Excel file · date fields · line chart · reference line · annotations |
| **Course themes** | Methodology (text-based indicators); the vocabulary of the whole course |

---

## What session 01 is for

| Geopolitics | Data & Tableau | International business |
|---|---|---|
| Distinguish **risk** from **uncertainty**, and **political**, **country** and **geopolitical** risk from one another | Install Tableau Desktop and Tableau Prep under the academic licence | Name the channels through which geopolitical events reach a firm's costs, revenues and assets |
| Classify indicators as **event-based, text-based, expert-based, structural, market-based or firm-level** | Connect to an `.xls` file, set a date field, build a line chart | Say why a firm might delay an investment when GPR spikes |
| State what the GPR index measures — and what it cannot | Add a reference line at the base-period mean of 100 and annotate the spikes | Say why a newspaper-attention index is not a risk score for a subsidiary |
